# icon-logo · 图标标识域

> 纯参数化 SVG。图标是**几何**问题，不是布局问题 —— 所以不走 HTML 路线。

---

## 1. 路由

```
用户要图标/logo
  ├─ 系统图标（线性/面性）→ 参数化 SVG，网格对齐到 24/48 基准
  ├─ 字母标 / 图形标 → 参数化 SVG + 可选字体
  └─ 复杂插画 → 超出本域，说明并另议
```

## 2. 图标网格

| 项 | 规范 |
|---|---|
| 基准尺寸 | 24×24（线性图标）、48×48（面性图标） |
| 描边宽度 | 2px（24 基准）、3px（48 基准） |
| 圆角 | 描边端点 `stroke-linecap="round"` |
| 安全区 | 图标内容占 20×20，四周留 2px |
| 关键线 | 对齐到 2px 网格，不落半像素 |

## 3. 设计语言

- **单色优先。** 图标先做成单色可辨，再加色。多色 Logo 强调色 ≤3。
- 线宽统一：一组图标里所有描边同宽。
- 端点圆角统一：一组图标要么全圆头，要么全平头，不混。
- 不用渐变、阴影、3D。扁平是默认，也是印刷要求。
- 颜色走 token：`colors.ink`（单色）、`colors.accent[0]`（品牌色）。

## 4. 验收标准

- [ ] SVG 无宽度硬编码以外的多余属性；`viewBox` 存在
- [ ] 所有关键坐标是 2px 网格整数（脚本自查）
- [ ] 单色版可辨（转灰度看）
- [ ] 描边宽度组内统一（脚本自查）
- [ ] 24px 与 48px 两个尺寸下都清晰
- [ ] 视觉裁判 PASS

## 5. 什么时候停下来问人

- 用户要「注册成商标的近似图形」→ 拒绝抄袭，问原创方向
- 需要字体转曲 → 问字体授权
- 要导出 ICO/ICNS 多尺寸包 → 说明当前输出 SVG，问是否需要位图包

## 6. 快速入口

```bash
python -m domains.icon-logo.scripts.icon_gen <spec.json> -o icon.svg
python -m backends.png icon.svg -o icon.png --width 256
```
