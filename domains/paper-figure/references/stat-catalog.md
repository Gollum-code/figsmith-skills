# paper-figure · 科研统计图目录

> 20 类科研统计图。**所有类型的数据必须来自冻结表，一个点都不许手挪。**
> 机器可读版：`catalog.json`。

---

## 一、分布型（5 类）

| ID | 图型 | 数据形态 | 误差声明 |
|---|---|---|---|
| `hist` | 直方图 | 一维连续 | 可带 SD 带 |
| `kde` | 核密度 | 一维连续 | 可带 CI 带 |
| `box` | 箱线图 | 多组分布 | 箱体即 IQR，须说明须线定义 |
| `violin` | 小提琴图 | 多组分布 | 同箱线图 |
| `ridge` | 山脊图 | 多组分布堆叠 | 同 KDE |

## 二、比较型（6 类）

| ID | 图型 | 数据形态 | 注意 |
|---|---|---|---|
| `bar` | 条形图 | 分类 × 数值 | 基线必须为 0 |
| `bar_grouped` | 分组条形 | 分类 × 2+ 系列 | 组内间距 < 组间 |
| `bar_stacked` | 堆叠条形 | 分类 × 构成 | 总量可读 |
| `dot_plot` | 点图 | 分类 × 数值 | 比条形图更省墨 |
| `errorbar` | 误差棒图 | 均值 ± 误差 | **必须声明 CI/SD/SE** |
| `forest` | 森林图 | 效应量 ± CI | 中轴 = 无效线 |

## 三、关系型（5 类）

| ID | 图型 | 数据形态 | 注意 |
|---|---|---|---|
| `scatter` | 散点图 | 双连续 | 可加回归线 + CI 带 |
| `line` | 折线图 | 有序 × 连续 | x 必须有序 |
| `bubble` | 气泡图 | 三变量 | 面积编码，别用半径 |
| `heatmap` | 热图 | 矩阵 | 连续色板，标注数值 |
| `contour` | 等值线图 | 网格函数 | 标注关键等值线 |

## 四、构成与流动（4 类）

| ID | 图型 | 数据形态 | 注意 |
|---|---|---|---|
| `pie` | 饼图 | 占比 | 仅 ≤5 类，否则用条形 |
| `donut` | 环形图 | 占比 | 同饼图 |
| `stacked_area` | 堆叠面积 | 时序构成 | 总量趋势可读 |
| `sankey` | 桑基图 | 流量守恒 | 入口总量 = 出口总量 |

## 数据冻结纪律（IR 2.6）

每个统计图必须带：

```jsonc
"data": {
  "source": "data/xxx.csv",          // 真实文件路径
  "series": [
    { "name": "实验组", "x": [...], "y": [...],
      "yerr": [...], "error_kind": "SD" }   // error_kind 必填
  ],
  "units": { "x": "s", "y": "a.u." },
  "statistics": { "test": "two-sided t-test", "alpha": 0.05, "n": 240 }
}
```

缺失任一项 → **停下来问人**，不许默认。

## 显著性标注

- 星标只标在**实际做过检验**的对比上
- 无检验就说「无显著性检验」，别画星
- 多重比较须说明校正方法（Bonferroni / FDR）

## 坐标轴

- 必须有单位；无量纲写 `a.u.`
- 条形图基线为 0，折线图可截断但**必须标断点**
- 对数轴须在轴标签写明 `log scale`

## 期刊投稿专项

- 颜色：投稿初期用灰度可分辨的 CVD 安全色板
- 字号：印刷后不低于 6pt（academic token 最小 7.5pt，留余量）
- 线宽：数据线 ≥1.2px，网格 ≤0.5px
- 格式：SVG（矢量）+ PDF（600dpi）+ PNG（300dpi 供审稿）
